달토끼 소리 녹음

달마다 화면에서 들리는 소리를 하나씩 녹음합니다. 목록은 달과 밤 순서로 나오고, 아직 녹음하지 않은 첫 말에서 시작합니다. 녹음은 이 브라우저에 저장되니 여러 번에 나눠서 해도 됩니다. 다 하지 않고 일부만 올려도 되고, 녹음이 없는 말은 기기 음성으로 대신 나옵니다.

  • 조용한 방에서, 입과 마이크 사이를 한 뼘 정도로 두세요.
  • 처음부터 끝까지 같은 목소리 크기와 같은 속도로 해 주세요. 앞뒤 빈 소리와 음량은 도구가 자동으로 맞춥니다.
  • 자음 소리 [그], [느]와 받침 소리 [윽], [은]은 짧게 끊어서 해 주세요. 아이가 듣는 건 글자 이름이 아니라 소리입니다.
  • 사람 목소리 대신 AI 목소리로 채워도 됩니다. 아래 AI 목소리 설정에서 한 번만 준비하면, 말마다 AI 목소리 단추로 만들어 들어 보고 저장할 수 있어요. AI로 저장한 말도 나중에 녹음하면 사람 목소리로 바뀝니다.
  • 단축키: 스페이스 녹음 시작과 끝, P 다시 듣기, → 다음, ← 이전, A AI 목소리 만들기, S AI 목소리 저장
AI 목소리 설정

TTS 모델은 모델마다 하루 한도(Tier 1에서 Flash 계열 100개, 2.5 Pro 50개)와 분당 한도(10개)가 따로 있어요. 한 모델이 하루 한도에 걸리면 여기서 다른 모델로 바꾸고 이어서 채우면 됩니다. 한도는 태평양 시간 자정(인디애나 새벽 3시쯤)에 다시 채워집니다.

처음부터 끝까지 한 목소리로 맞추는 것이 좋아요. 키를 저장하면 한국어 목소리 라이브러리도 함께 불러옵니다.

API 키 받는 법 (한 번만)
  1. aistudio.google.com 에 Google 계정으로 로그인합니다.
  2. 왼쪽 아래 Get API key를 누르고 Create API key로 키를 만듭니다. AQ.로 시작하는 키가 나오면 맞습니다.
  3. 많이 만들 때는 무료 한도에 금방 걸릴 수 있어요. 그럴 때는 같은 화면에서 결제(유료 등급)를 켜면 됩니다. 한도에 걸리면 도구가 잠깐 기다렸다가 다시 시도합니다.
  4. 키를 위 칸에 붙여 넣고 저장합니다. 키는 이 브라우저에만 남고, 코드나 저장소, 내려받는 zip에는 들어가지 않습니다.

저장소에 올리는 법
  1. 내려받은 zip을 풀면 audio 폴더가 나옵니다. zip 파일 자체는 올리지 않습니다.
  2. 저장소 맨 위(홈 index.html이 있는 곳)에서 Add file, Upload files를 누르고 audio 폴더를 폴더째 끌어다 놓습니다. 폴더 안의 파일만 끌어다 놓으면 저장소 맨 위에 흩어집니다.
  3. GitHub 웹에서는 한 번에 100개까지만 올라가서, 어느 쪽으로 받든 zip 하나에 100개(manifest.json 포함)까지만 담습니다. 1부, 2부를 차례로 받아 하나씩 저장소 맨 위에 폴더째 끌어다 놓으면 같은 audio 폴더 안에 합쳐집니다.
  4. 평소에는 새로 만들거나 바꾼 것만 받기를 쓰면 됩니다. 나눠진 부분을 모두 받으면 그때를 기준으로 삼아, 다음에는 그 뒤에 만들거나 바꾼 말만 담깁니다. 전체 내려받기는 저장소를 처음부터 다시 맞추고 싶을 때 씁니다.
  5. manifest.json 은 두 방법 모두 늘 1부에 들어가고, 사이트에 있는 목록과 이 브라우저의 것을 모두 합친 전체 목록입니다. 그래서 1부는 꼭 올려야 합니다.
  6. 확인: https://hyeonhoyu.github.io/daltokki/audio/manifest.json 을 열었을 때 글이 보이면 맞게 올라간 것입니다.
  7. 다시 녹음한 뒤에는 새로 내려받아 audio 폴더 전체를 덮어쓰면 됩니다. 파일 이름이 글자마다 정해져 있어서 겹치지 않습니다.
