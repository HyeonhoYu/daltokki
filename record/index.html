달토끼 소리 녹음

달마다 화면에서 들리는 소리를 하나씩 녹음합니다. 목록은 달과 밤 순서로 나오고, 아직 녹음하지 않은 첫 말에서 시작합니다. 녹음은 이 브라우저에 저장되니 여러 번에 나눠서 해도 됩니다. 다 하지 않고 일부만 올려도 되고, 녹음이 없는 말은 기기 음성으로 대신 나옵니다.

  • 조용한 방에서, 입과 마이크 사이를 한 뼘 정도로 두세요.
  • 처음부터 끝까지 같은 목소리 크기와 같은 속도로 해 주세요. 앞뒤 빈 소리와 음량은 도구가 자동으로 맞춥니다.
  • 자음 소리 [그], [느]와 받침 소리 [윽], [은]은 짧게 끊어서 해 주세요. 아이가 듣는 건 글자 이름이 아니라 소리입니다.
  • 사람 목소리 대신 AI 목소리로 채워도 됩니다. 아래 AI 목소리 설정에서 한 번만 준비하면, 말마다 AI 목소리 단추로 만들어 들어 보고 저장할 수 있어요. AI로 저장한 말도 나중에 녹음하면 사람 목소리로 바뀝니다.
  • 단축키: 스페이스 녹음 시작과 끝, P 다시 듣기, → 다음, ← 이전, A AI 목소리 만들기, S AI 목소리 저장
AI 목소리 설정

Chirp3-HD가 가장 사람 같고, Neural2와 Wavenet이 그다음, Standard가 가장 기계 같은 소리입니다. 처음부터 끝까지 한 목소리로 맞추는 것이 좋아요.

아이들이 듣기 좋게 빠르기는 0.85 정도를 권합니다. Chirp3-HD 목소리는 높낮이 조절이 되지 않아 빠르기만 적용됩니다.

API 키 만드는 법 (한 번만)
  1. console.cloud.google.com 에서 프로젝트를 하나 만들고 결제 계정을 연결합니다. 무료 한도 안에서는 요금이 나오지 않지만, 연결은 해 두어야 음성 기능이 켜집니다.
  2. API 및 서비스, 라이브러리에서 Cloud Text-to-Speech API를 찾아 사용 설정합니다.
  3. API 및 서비스, 사용자 인증 정보에서 API 키를 만듭니다.
  4. 그 키의 제한 설정에서 애플리케이션 제한은 웹사이트로 하고 https://hyeonhoyu.github.io/* 를 넣습니다. API 제한은 Cloud Text-to-Speech API 하나만 고릅니다. 이렇게 하면 키가 새어 나가도 다른 곳에서는 쓸 수 없어요.
  5. 키를 위 칸에 붙여 넣고 저장합니다. 키는 이 브라우저에만 남고, 코드나 저장소, 내려받는 zip에는 들어가지 않습니다.

저장소에 올리는 법
  1. 내려받은 zip을 풀면 audio 폴더가 나옵니다. zip 파일 자체는 올리지 않습니다.
  2. 저장소 맨 위(홈 index.html이 있는 곳)에서 Add file, Upload files를 누르고 audio 폴더를 폴더째 끌어다 놓습니다. 폴더 안의 파일만 끌어다 놓으면 저장소 맨 위에 흩어집니다.
  3. GitHub 웹에서는 한 번에 100개까지만 올라갑니다. 파일이 많으면 도구가 1부, 2부로 나눠 주니, 둘 다 같은 방법으로 저장소 맨 위에 폴더째 끌어다 놓으면 같은 audio 폴더 안에 합쳐집니다.
  4. 확인: https://hyeonhoyu.github.io/daltokki/audio/manifest.json 을 열었을 때 글이 보이면 맞게 올라간 것입니다.
  5. 다시 녹음한 뒤에는 새로 내려받아 audio 폴더 전체를 덮어쓰면 됩니다. 파일 이름이 글자마다 정해져 있어서 겹치지 않습니다.
